# Phase 1 — UI Design Contract

> Visual and interaction contract for the "Movie League" reskin. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Ground truth for visuals: `.planning/phases/01-ui-redesign/MOCKUP-NOTES.md` (transcribed from two user-supplied screenshots — no downloadable mockup file exists). Ground truth for data: `backend/app/models.py` / `backend/data/league_data.json`.

**Scope decision log (confirmed with user 2026-08-17):** the mockup depicts a fictional "fantasy awards league" with features this app's data model does not have (draft slots/categories, projections, shared ownership %, waivers/trades, claim/watchlist, a lineup-editing CTA, per-title poster art, a 6-category points system, and a real event/schedule feed). Per explicit user decision, this phase maps the mockup's *visual system* onto the *real* data model rather than inventing backend features. Two widgets are exceptions: "THIS WEEK" and "CAMPAIGN TRACKER" are kept as **static, illustrative-only** UI elements (hardcoded content, visually present, clearly not wired to live data) purely for visual completeness — see Illustrative Widgets section. Every other fictional-only element is omitted. Full mapping table is in Component & Data Mapping below.

## Spacing Scale

Declared values (multiples of 4, standard 8-point scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/dot gaps, chip inline padding |
| sm | 8px | Compact element spacing, status-dot-to-label gap |
| md | 16px | Default element spacing, table cell padding |
| lg | 24px | Section padding, card/table block padding |
| xl | 32px | Layout gaps between major page sections |
| 2xl | 48px | Page header block spacing |
| 3xl | 64px | Not used at this phase's scale (single-page app, no long-scroll sections) |

Exceptions:
- Table row minimum height: **44px** (touch-target size for the clickable expand row, overrides the 16px rhythm when content is shorter)
- Status dot diameter: **8px** (fixed, not on the spacing scale — it's a glyph, not a spacing unit)
- Hairline dividers: **1px** solid border, not a spacing value — used instead of shadows/heavy borders everywhere (see Color section)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (700 for in-row emphasis) | 1.5 |
| Label | 11px | 700 | 1.4 |
| Heading | 20px | 700 | 1.2 |
| Display | 36px (28px mobile ≤600px) | 700 | 1.15 |

Font-family assignment per role (only 2 weights — 400/700 — used across the whole contract):

- **Body** → `--font-body: 'Inter', system-ui, sans-serif` — movie/row titles, subtitle lines (director/context), penalty notes, `who_watched` list, empty/error state copy. Weight 400 default, 700 for the title itself within a row.
- **Label** → `--font-label: 'JetBrains Mono', 'IBM Plex Mono', monospace`, uppercase, letter-spacing 0.08em — nav items, table column headers (ROUND/TITLE/STATUS/PTS/WATCHED), status pill text, round badges (R1–R6), meta lines ("2ND OF 5 · 6 ROUNDS").
- **Heading** → same `--font-label` mono family, weight 700, not uppercase-forced — stat-block big numbers (round total, ratings, ROI, watched count), section titles (POINTS LEDGER, CAMPAIGN TRACKER, THIS WEEK), the PTS column value in table rows.
- **Display** → `--font-display: 'Playfair Display', Georgia, serif` — reserved for exactly two things: the owner's name in the player header (equivalent of mockup's team name), and the movie title in the expanded detail panel (equivalent of mockup's title-detail hero). Never used for anything else (not nav, not labels, not body).

## Color

Background/surface follow the mockup's near-black flat aesthetic. **No box-shadow glows** anywhere (explicit mockup note: "no heavy borders/shadows anywhere, flat dark panel, hairline dividers only") — this replaces the current build's rank-1/2/3 glow/box-shadow treatment.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0a0f` | Page background |
| Secondary (30%) | `#121218` (raised/hover: `#17171f`) | Table rows, player-card surface, sidebar panels, nav bar |
| Accent (10%) | `#e0a339` | Reserved for: rank-1 leader treatment (number color + 2px top-accent border, no glow), positive point deltas/totals, "SCORED" status dot, positive progress-bar fill in Points Ledger, focus-visible ring |
| Destructive | `#f2545b` | Reserved for: "AT RISK" status dot, negative point deltas/totals, penalty progress-bar fill, error-state text/icon |

Additional status-only color (status dots require a third hue beyond accent/destructive; kept to one swatch to preserve palette discipline):

| Role | Value | Usage |
|------|-------|-------|
| Status: informational | `#5b9bd5` | Reserved for: "AWAITING SCORE" status dot only. Not used anywhere else (not buttons, not text, not borders). |

Text and structural colors (not part of the 60/30/10 count — these are neutrals/hairlines):

| Token | Value | Usage |
|-------|-------|-------|
| `--text` | `#e4e7f5` | Primary text |
| `--text-dim` | `#8890ab` | Secondary/meta text, "PENDING / NO PICK" status dot color, rank-2+/other rank numbers (no distinct color per rank beyond rank-1) |
| `--text-faint` | `#4d5372` | Tertiary/disabled text, hairline-adjacent captions |
| `--border` | `#1c1c26` | Hairline row/section dividers |
| `--border-bright` | `#2a2a38` | Slightly stronger hairline (e.g. expanded-row boundary) |

Accent reserved for: rank-1 leader number/top-border, positive point deltas, "SCORED" status dot, positive Points Ledger bars, focus ring. **Never** used for backgrounds, decorative fills, or default button states (no primary CTA exists in this phase — see Copywriting Contract).

## Component & Data Mapping

Maps mockup elements to the **existing** components (`Leaderboard.jsx`, `PlayerCard.jsx`, `MovieCard.jsx`) and their real data fields. `OwnerDetail.jsx` is currently unused dead code (not imported by any live component per `ARCHITECTURE.md`/grep) — leave as-is, out of scope for this phase.

### Roster view (`Leaderboard.jsx` → `PlayerCard.jsx`)

The app shows all 5 owners ranked (current IA), not a single "my team" page — keep this IA. Each `PlayerCard` is reskinned as one mockup-style roster table block instead of a card grid.

| Mockup element | Real field / decision |
|---|---|
| Page header stat cluster (POINTS/PROJECTED/SLOTS FILLED) | Per-owner header inside `PlayerCard`: **TOTAL** (`summary.total`), **RATING** (`summary.rating_score`), **FINANCIAL** (`summary.financial_score`), **WATCH** (`summary.watch_points`) — reuse existing chip data, restyle as label-above-number stat blocks (mockup pattern) instead of pill chips |
| "SLOT" column | Relabeled **ROUND** — values R1–R6 (`m.round`), no fictional category names |
| "TITLE" column | `m.movie`, with `Not yet picked` fallback (existing copy, unchanged). No subtitle/director line — no such field exists; omit the mockup's muted subtitle row |
| "STATUS" column | Derived status pill — see Status Pill Token Table below |
| "PTS" column | `m.total`, Heading role, amber if > 0 / red if < 0 / `--text-dim` if 0 (existing sign logic, restyled) |
| "PROJ" column | **Omitted** — no projection model exists, do not fabricate |
| "OWNED" column | Relabeled **WATCHED** — `who_watched.length` / total owner count (e.g. "3/5"), Body role, `--text-dim` |
| Highlighted/active row (amber-tinted bg) | Not used — no "about to lock" concept exists. Omit. |
| Bench/Vault grayed rows | Not applicable — no bench/vault slots exist; all 6 rounds are equally active |
| "SAVE LINEUP" CTA | Omitted (see Copywriting Contract) |
| "THIS WEEK" sidebar | Kept as **static illustrative widget** — see Illustrative Widgets section |
| "OPEN ROSTER MOVES" / WAIVERS / TRADE BLOCK | Omitted — no waiver/trade mechanic exists in this app |
| Rank-1/2/3 glow styling (current app) | Replaced with flat treatment: rank-1 gets amber number color + 2px amber top-border accent (no shadow/glow); ranks 2+ use `--text-dim`, no special color per rank |

### Movie detail view (`MovieCard.jsx` expanded state)

Renders inline as a full-width expanded row beneath the clicked table row (same interaction pattern as today's `.movie-card.expanded`, restyled).

| Mockup element | Real field / decision |
|---|---|
| Hero "KEY ART" banner | No poster/backdrop field exists (TMDB enrich doesn't fetch one). Render as a **fixed-height gradient/pattern placeholder panel** (`--surface` → `--surface-raised` diagonal gradient, no `<img>`), identical treatment for every movie. Movie title (Display role, serif) sits directly below it, same as mockup layout. |
| Meta line under title | `DIR. ...` etc. omitted (no director field). Show what's real: `R{round} · {owner}'s pick` in Label role |
| CLAIM/WATCHLIST buttons | Omitted — no waiver/claim mechanic exists |
| Stat strip (5 blocks) | 4 blocks from real fields (Heading role numbers, Label role captions): **ROUND TOTAL** (`m.total`, amber/red by sign) — caption "RATING {rating_score:+} · FIN {financial_score:+} · WATCH +{watch_points}"; **RATING** (`m.imdb` as headline, or `—` if null) — caption listing available metrics e.g. "RT {rt_crit}% · LB {letterboxd}"; **ROI** (`m.roi.toFixed(2)`×, or `—`) — caption "BUDGET ${budget}M / GROSS ${gross}M"; **WATCHED** (`who_watched.length`/owner count) — caption comma-joined names or "Not yet watched" |
| Points Ledger (6 fictional categories) | Real 4 categories only, same as current `MovieDetail` logic, restyled as mockup-style rows (label + progress bar + bold value), only rendered if nonzero: Rating score, Financial score, Watch points, Penalties. Progress-bar fill color rule (explicit, not decorative): **amber** fill for Rating/Financial/Watch rows (positive-contribution categories), **red** fill for Penalties row. Bar width = `min(abs(value) / cap, 100%)` where cap is illustrative-only per category: Rating cap 40, Financial cap 15, Watch cap 10, Penalty cap 30 — approximate visual scaling, not a scoring formula, documented here so the executor doesn't invent different caps. |
| Campaign Tracker (timeline) | Kept as **static illustrative widget** — see Illustrative Widgets section |
| League Ownership sidebar → "ROSTERED BY" | Real, lightweight: single-line callout "Picked by **{owner}** · Round {round}" in an amber-bordered callout card (reuses mockup's highlight-card visual pattern with real, already-known data — no new field needed) |
| League Ownership sidebar → "SIMILAR AVAILABLE" | **Omitted** — no undrafted-movie pool or "similar titles" concept exists in a one-pick-per-round-per-owner model |
| Bottom export/share bar | Not part of the app design (Claude-UI-Builder export chrome) — already excluded per MOCKUP-NOTES |

### Status Pill Token Table

Four real, derivable states (replacing the mockup's 8 fictional narrative states). Precedence: penalty check first, then pending/awaiting checks, else scored.

| State | Dot color | Label | Condition |
|---|---|---|---|
| No pick | `--text-dim` (#8890ab) | "NO PICK" | `!m.movie` |
| Awaiting score | `#5b9bd5` (informational) | "AWAITING SCORE" | `m.movie` truthy AND `m.imdb === null && m.gross === null && m.rt_crit === null` (mirrors existing `isPending` logic in `MovieCard.jsx`) |
| At risk | `#f2545b` (destructive) | "AT RISK" | `m.penalties !== 0` (checked before "scored", takes precedence) |
| Scored | `#e0a339` (accent) | "SCORED" | has ratings/financials entered, `penalties === 0` |

## Illustrative Widgets (static, non-live content)

Per explicit user decision: these two mockup widgets are kept for visual completeness but are **hardcoded/static**, not wired to any backend data source. Each must carry a small muted disclaimer so it's never mistaken for live data: caption text **"Illustrative — not live data"** in `--text-faint`, Label role, placed once per widget (small corner note, not per-item).

### THIS WEEK (page-level sidebar, appears once above the owner list)

Two-column layout on desktop (main content + sidebar), stacked single column on mobile (≤600px, sidebar renders below the owner list). Hardcoded content (do not vary per owner/session):

1. **"Scores update after movie night"** — tag "ALL ROUNDS" — body "Ratings and financials are entered manually after each round wraps."
2. **"New picks lock each cycle"** — tag "ALL OWNERS" — body "Once a round's movie is set, it can't be changed."

### CAMPAIGN TRACKER (inside movie detail expanded panel, middle column)

Fixed 3-item vertical timeline, same hardcoded copy for every movie (dot colors follow the mockup's amber/blue/gray pattern purely decoratively here, not tied to real recency):

1. Dot amber — **"Movie picked"** — "Selected for this round" 
2. Dot blue — **"Scores entered"** — "Manual entry after release"
3. Dot gray — **"TMDB enrichment available"** — "Budget & gross can be pulled from TMDB"

No point-delta numbers are shown on these rows (mockup's "+24/+6/+20" deltas would imply real scoring events — omit to avoid misleading the reader).

## Layout & Responsive Notes

- Page grid: two columns on desktop (≥900px) — main content (owner roster tables) + THIS WEEK sidebar (~30% width, matches mockup ratio). Single column stacked below 900px, sidebar moves below content.
- Table rows: hairline `--border` divider between rows, no per-row card border/shadow (replaces current `.movie-card` tile-grid treatment).
- Expanded detail row spans full table width (existing `grid-column: 1 / -1` pattern in current CSS, kept).
- Existing breakpoint at 600px (current `styles.css`) is kept for mobile-specific overrides (Display role drops to 28px, stat strip wraps to 2-column grid).

## Accessibility (carried over, unchanged)

- Row click-to-expand keeps existing `role="button"`, `tabIndex`, `aria-expanded`, and Enter/Space keyboard handling from `MovieCard.jsx` — do not regress this.
- `prefers-reduced-motion` media query (already in `styles.css`) is kept as-is.
- Status dots must not be color-only signals: always pair the dot with its text label (already specified above — never render a dot without adjacent Label-role text).

## Superseded Tokens (remove from `styles.css`)

Replace entirely, do not keep as fallback: `--font-display: 'Bebas Neue'`, the gradient-text `.header h1` treatment, all `rank-1/2/3` `box-shadow` glow rules, the emoji-prefixed `ScoreChip`/`mini-chip` labels (★ $ 👁 ⚠), and the `.movie-grid` CSS-grid tile layout (replaced by table rows per this contract).
